Android APK Installation Guide

Method 1
Direct Native WebAPK (Fastest - No Android Studio needed)

1. Open this app in Google Chrome or Microsoft Edge on your Android phone.

2. Tap the Chrome menu (⋮) -> Select "Install app" or "Add to Home Screen".

3. Android will automatically compile and install a native .apk on your home screen and app drawer with 100% offline capability.

Method 2
1-Minute Cloud APK Generator (PWABuilder)

1. Open PWABuilder.com.

2. Enter your app's URL or upload this folder.

3. Click "Generate Android APK" -> Download signed APK ready for side-loading!

Method 3
Full Android Studio Project (Included in Workspace)

The native Android project is located at savewise-app/android/.

1. Open Android Studio -> Select Open Project -> choose savewise-app/android.

2. Click Build -> Build Bundle(s) / APK(s) -> Build APK(s).

3. Your debug/release APK will be generated in app/build/outputs/apk/!
